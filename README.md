# 🍱 실시간 점심 메뉴 투표 웹 서비스 (Day 3)

점심 메뉴 4개(비빔밥, 돈까스, 국밥, 샐러드) 중 마음에 드는 메뉴를 골라 실시간으로 투표하고, 결과를 구글 스프레드시트와 실시간 연동하여 확인하는 인터랙티브 웹 애플리케이션입니다.

## 🚀 주요 기능
- **메뉴 선택**: 비빔밥(🍚), 돈까스(🍱), 국밥(🍲), 샐러드(🥗) 4가지 메뉴 카드 선택
- **투표자 이름 입력**: 선택 사항 (미입력 시 '익명'으로 시트에 기록)
- **구글 시트 실시간 연동 (읽기 & 쓰기)**:
  - 투표 시 구글 스프레드시트에 새로운 행(`timestamp`, `menu`, `volter`)으로 자동 저장
  - 시트 데이터를 실시간 집계하여 백분율(%) 및 득표수 갱신
  - 데이터가 없을 경우 `0표 (0%)`로 안전하게 예외 처리
- **1위 메뉴 하이라이트**: 최다 득표 메뉴에 👑 1위 배지 및 강조 애니메이션 적용
- **동기화 및 새로고침**: 시트 연동 상태(🟢) 및 '최신화' 버튼 제공
- **반응형 웹**: 모바일 및 데스크탑 화면 완벽 지원

## ⚙️ 구글 스프레드시트 실시간 쓰기 연동 방법 (1회 설정)

구글 스프레드시트는 보안 정책상 익명 브라우저의 직접적인 쓰기(Append)를 차단하므로, 간단한 **Google Apps Script 웹 앱**을 통해 안전하게 저장됩니다.

1. 연동할 [구글 스프레드시트](https://docs.google.com/spreadsheets/d/1VnlP_HWFiANJWV4D17ecovgr2j9hzsdw50FtcCcA7E8/edit?usp=sharing) 열기
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]** 클릭
3. 프로젝트 내 [google-apps-script.js](google-apps-script.js) 파일의 코드를 복사하여 붙여넣고 저장 (`Ctrl + S`)
4. 우측 상단 **[배포] > [새 배포]** 클릭:
   - 유형: **웹 앱 (Web app)**
   - 설명: `점심 메뉴 투표 API`
   - 다음 사용자 권한으로 실행: **나 (내 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자 (Anyone)** 👈 *필수*
5. **[배포]** 클릭 후 권한 승인 완료
6. 발급된 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사하여 웹 화면의 **[⚙️ 연동 설정]** 창에 입력 후 저장!
