# 🍱 실시간 점심 메뉴 투표 웹 서비스 (Day 3)

점심 메뉴 4개(비빔밥, 돈까스, 국밥, 샐러드) 중 마음에 드는 메뉴를 골라 실시간으로 투표하고 결과를 확인하는 인터랙티브 웹 애플리케이션입니다.

## 🚀 주요 기능
- **메뉴 선택**: 비빔밥(🍚), 돈까스(🍱), 국밥(🍲), 샐러드(🥗) 4가지 메뉴 카드 선택
- **실시간 투표 및 결과 집계**: 투표 시 즉시 백분율(%) 및 득표수 갱신
- **1위 메뉴 하이라이트**: 최다 득표 메뉴에 👑 1위 배지 및 강조 애니메이션 적용
- **데이터 보존**: `localStorage`를 활용하여 새로고침 후에도 투표 결과 유지
- **투표 초기화**: 언제든 투표 결과를 0표로 리셋 가능
- **반응형 웹**: 모바일 및 데스크탑 화면 지원

## 🛠️ 기술 스택
- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, Keyframe Animations)
- JavaScript (Vanilla JS, LocalStorage API)
